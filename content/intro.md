Title: Introduction and Welcome
Date: 2026-07-30 12:00
Category: General

Welcome to my new project space where I will be documenting my steps preparing and using the TensTorrent Blackhole 150a card for local LLM use. I hope this will be of use to the current and future TensTorrent community. 

I am an <A HREF="https://leddy.uwindsor.ca/staff/pascal-calarco">academic librarian</a> at the <A HREF="https://uwindsor.ca">University of Windsor</A>, in Windsor, Canada. I have worked in technology services in academic research libraries in the United States and Canada for 31 years. I started programming in my first position, learning perl and CGI scripting for web forms.

These days, I work in scholarly communications, which basically means I help faculty and students at the University with publishing their research -- finding a suitable journal for their topic, starting new Diamond Open Access journals hosted by our library, and depositing their publications into our institutional repository, <A HREF="https://uwindsor.scholaris.ca/">Scholarship@UWindsor</A>.

I started using AI chatbots when OpenAI first released their chatbot several years ago, and subscribed to it for a year. When I bought a new Google Pixel phone in Febuary, 2025 that came with <A HREF="https://gemini.google.com">Google Gemini Pro</A> and other goodies for a year, I started using Gemini for all kinds of things -- helping me assess my hi-fi audio components for future upgrades, car shopping and comparative assessment, bass guitar string recommendations, to name a few. 

In the Spring and Summer of 2025, we migrated our institutional repository to a new shared open source platform, <A HREF="https://dspace.org/">DSpace</A> and I had a lot of data transformation and ingestion to do in the new repository. I worked with another librarian at <A HREF="https://uwo.ca/">Western University</A>, who shared some python scripts that she'd developed, since we were both migrating from the same platform. I started asking, "I wonder if Gemini could help me code some more python to automate this work further?" I developed a set of python scripts to help harvest faculty and student journal articles, book chapters and books, conference proceedings and other types of research outputs and transformed the metadata from API endpoints that we had access to and packaged the bitstreams and metadata into what DSpace was expecting. I'm slowly getting these released on my <A HREF="https://github.com/pvcalarco/">GitHub</A>.

I joined a community project that I found, and got more interested in agentic AI and in particular, local LLM hosting and use. I had a couple good computers but they did not have very large GPUs (a Dell XPS workstation from 2020, with 64GB RAM and an NVIDIA RTX 2060 6GB VRAM, and a Dell G15 i9-based gaming laptop with 32GB RAM and an NVIDIA 4060 card with 8GB VRAM). So I needed a new GPU, probably at least 24GB VRAM so I could run decent models.

I've been a linux user for many years. I started with Red Hat Linux 3.0.3 (1995), which was an early, historic release that first made available the Red Hat Package Manager (RPM), and ran this on a 486 PC I had at the time. I eventually moved to Fedora Linux when Core 2 was released in 2004. I've been using that distribution ever since, and I was a <A HREF="https://fedoraproject.org/wiki/User:Pcalarco">community contributor</A> from 2008-2014. 

So, I've always been a strong advocate and user of free and open source software. I wanted to find a solution that aligned with my values and in June 2026, I discovered <A HREF="https://tenstorrent.com">TensTorrent</A>. RISC V architecture that was open source. Hardware all open source. Software all open source. Perfect. 

I am starting with a TensTorrent Blackhole 150a 32GB card. My first work is crafting a custom PC build, with quite specific requirements for motherboard, RAM and PCIe slots. In my next post, I'll go over those components and why I selected them.
